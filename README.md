# Помощник по заявкам на строительство домов

Небольшая страница для менеджера. В неё вставляют текст обращения, нажимают «Обработать» и получают карточку: тип заявки, известные данные, чего не хватает, следующий шаг и черновик ответа.

Текст разбирает сервис GigaChat. Приложение само ничего не придумывает и не хранит заявки: базы, входа по паролю и мессенджеров здесь нет.

Все примеры в кнопках — вымышленные.

## Что понадобится

1. **Python 3.11 или новее** — язык, на котором написана программа. Если его нет, скачайте установщик с [python.org](https://www.python.org/downloads/) и при установке отметьте добавление Python в PATH.
2. **Интернет** — без него GigaChat не ответит.
3. **Ключ GigaChat** — секретная строка доступа. Её вписывают только в файл `.env` на вашем компьютере. В чат, письмо и git её отправлять не нужно.

Библиотеки, которые ставятся одной командой:

| Библиотека | Зачем она |
|---|---|
| Streamlit | Показывает страницу в браузере: поле, кнопки, карточку |
| gigachat | Официальный способ обратиться к GigaChat. Сама получает временный пропуск по вашему ключу |
| python-dotenv | Читает ключ из файла `.env`, чтобы он не был записан в коде |

## Где взять ключ

1. Откройте проект GigaChat API в личном кабинете Studio.
2. Слева выберите «Настройки API».
3. Нажмите «Получить ключ».
4. Скопируйте **Authorization Key** и сохраните его у себя. Строка показывается один раз.

Ключ — это не пароль от почты. Это допуск к API. Рядом в кабинете могут быть Client ID и Client Secret: в это приложение их вставлять не нужно, достаточно Authorization Key.

## Установка

Откройте терминал в папке проекта и выполните команды по очереди.

Проверить, что Python на месте:

```bash
python3 --version
```

Должна появиться версия 3.11 или выше.

Создать отдельное окружение. Это папка `.venv` с библиотеками только для этого проекта, чтобы они не смешались с другими программами:

```bash
python3 -m venv .venv
```

Включить окружение:

```bash
source .venv/bin/activate
```

На Windows команда другая: `.venv\Scripts\activate`.

Поставить библиотеки:

```bash
pip install -r requirements.txt
```

## Файл с ключом

Рядом с программой лежит образец `.env.example`. В нём нет секретов. Сделайте из него рабочий файл:

```bash
cp .env.example .env
```

Откройте `.env` в текстовом редакторе и впишите ключ в первую строку, без кавычек и пробелов:

```text
GIGACHAT_CREDENTIALS=сюда_ваш_ключ
```

Остальные строки можно не трогать. Пустые значения программа понимает так:

| Строка | Если оставить пустой |
|---|---|
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` — доступ для физического лица |
| `GIGACHAT_MODEL` | `GigaChat-2` |
| `GIGACHAT_VERIFY_SSL_CERTS` | проверка сертификата выключена, см. ниже |
| `GIGACHAT_CA_BUNDLE_FILE` | файл сертификата не используется |

Если кабинет оформлен на ИП или компанию, в `GIGACHAT_SCOPE` нужно другое значение:

- `GIGACHAT_API_B2B` — оплаченный пакет;
- `GIGACHAT_API_CORP` — оплата по факту использования.

Имя модели тоже можно заменить, если в вашем тарифе оно другое.

Файл `.env` уже указан в `.gitignore`, поэтому git его не заберёт.

## Почему в настройках есть сертификат

Сайт GigaChat использует сертификат Министерства цифрового развития. Обычный Python ему не доверяет и может оборвать соединение с ошибкой про certificate или SSL.

Для этого локального помощника проверка по умолчанию выключена: в `.env` оставьте `GIGACHAT_VERIFY_SSL_CERTS` пустым или напишите `false`. Ключ при этом всё равно не попадает в браузер.

Если захотите включить проверку:

1. Скачайте корневой сертификат «Russian Trusted Root CA» с [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt).
2. Укажите путь к файлу в `GIGACHAT_CA_BUNDLE_FILE`.
3. Поставьте `GIGACHAT_VERIFY_SSL_CERTS=true`.

## Запуск

Окружение должно быть включено (в начале строки терминала видно `(.venv)`). Затем:

```bash
streamlit run app.py
```

Терминал покажет адрес, обычно `http://localhost:8501`. Откройте его в браузере.

Остановить программу: в терминале нажмите Ctrl+C.

## Как проверить

На странице три кнопки подставляют учебные тексты. После каждой нажмите «Обработать».

1. **Полный сценарий.** Дом, участок, площадь, этажи, материал, бюджет и близкий срок. Ожидается тип «целевой» и следующий шаг в сторону отдела продаж. В черновике не должно быть выдуманной цены.
2. **Неполный сценарий.** Только вопрос «сколько стоит дом». Ожидается тип «неясно», список того, чего не хватает, и один-два уточняющих вопроса.
3. **Конфликтный сценарий.** Угроза суда и возврат денег. Ожидается передача человеку и спокойный черновик без обещаний компенсации.

Карточка показывает русские подписи, а не сырой технический ответ. Если ключ не вписан, нет интернета или сервис ответил с ошибкой, на странице появится короткое объяснение.

## Как устроены файлы

| Файл | Что внутри |
|---|---|
| `app.py` | Страница |
| `gigachat_client.py` | Общение с GigaChat и правила разбора |
| `samples.py` | Три учебные заявки |
| `requirements.txt` | Список библиотек |
| `.env.example` | Образец настроек без секретов |
| `.env` | Ваш ключ. Этот файл создаёте вы, в набор программы он не входит |
| `.gitignore` | Запрещает git забирать `.env` |

## Как программа решает тип заявки

- **Целевой** — строительство дома, бюджет назван, клиент просит предложение или готов начать в ближайший месяц.
- **Нецелевой** — запрос не про строительство дома, например ремонт квартиры.
- **Неясно** — тема похожа на стройку, но не хватает бюджета, этажности или срока.

Жалобы, суд и требования возврата уходят сотруднику. Программа не обещает цену, срок и скидку, если этого не было в тексте заявки.
