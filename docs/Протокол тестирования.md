# Протокол тестирования

Дата прогона: 22 октября 2026, 19:24–19:53 (МСК).

Проверялась страница помощника по заявкам на строительство частных домов. Разбор делает GigaChat. Перед запросом персональные данные заменяются токенами. После ответа карточка уходит в Битрикс24 через входящий вебхук. Портал работает в простом режиме CRM, поэтому запись сохраняется как сделка. Уведомление уходит сотруднику, от имени которого создан вебхук. Задача создаётся только если заявку должен разобрать человек.

Учебные контакты вымышленные. В журнал анонимизации и в запрос к модели имена, телефоны и почта не попадают.

## Пункты задания

| Пункт | Результат |
|---|---|
| Форма: имя, телефон, почта, текст заявки | Есть на странице |
| Анонимизация перед GigaChat | Имя, телефон, почта и адрес заменены токенами. В четырёх прогонах утечек нет |
| Входящий вебхук Битрикс24 с правами CRM, задач и уведомлений | Подключён через `B24_URL`. Четыре сделки созданы |
| Уведомление менеджеру | Отправлено во всех четырёх прогонах, ошибок нет |
| Четыре сценария | Целевой, нецелевой, жалоба, недостаточно данных |

Во всех четырёх прогонах Битрикс24 не вернул предупреждений: комментарий с карточкой записан в таймлайн, уведомление отправлено.

## Анонимизация

В текст для модели попали только токены.

- Целевой: `[ИМЯ_1]`, `[ТЕЛЕФОН_1]`, `[ПОЧТА_1]`, `[АДРЕС_1]`. «Московской области» в запросе нет, в карточке для сотрудника адрес восстановлен.
- Нецелевой, жалоба и недостаточно данных: `[ИМЯ_1]`, `[ТЕЛЕФОН_1]`, `[ПОЧТА_1]`.

Имена, телефоны и почты учебных заявок в обезличенном тексте не найдены.

## Расхождения

Расхождений с ожидаемым поведением нет. Повторный прогон после правок не потребовался.

## Улучшение

Фамилия и ИНН уже скрываются слоем анонимизации, поэтому отдельная правка под них не нужна.

Добавлен журнал `logs/anonymization.csv`. В него пишется время, состав токенов и обезличенный текст. Исходные персональные данные в файл не записываются. Четыре строки этого прогона лежат в журнале. Файл не попадает в git.
